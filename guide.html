1. Put it on your phone

  • Android (Chrome): open the app, tap the menu (three dots), then Add to Home screen or Install app.
  • iPhone (Safari): open the app, tap Share, then Add to Home Screen.
Your logs are saved on that phone only, in the browser. A different phone, a private window, or clearing browser data will not have them. Export now and then as a backup (see Backup).

Where your logs are saved

Your logs are saved in two places only:

  1. On your device. Every log you save stays in the app on your phone.
  2. In your own Google Sheet, as a backup, if you set up Google Sheets in section 4.

Nothing you save can be seen by anyone else, or reached from anywhere else, unless you share a copy yourself:

  • Share your Google Sheet with your supervisor when they need it.
  • Export the logs you need (Export tab) when you need documentation to support a specific incident.

2. Log a run

The bottom bar has six tabs: Today, Week, Schools, Voice, Settings, Export.

Set up once, in Settings

  1. Open Settings and enter your Driver Name and Bus Number, then tap Save Profile.
  2. Open Schools and make sure your schools are listed.

Each run, on the Today tab

  1. Check the Date, then choose the School.
  2. Enter the Route Number and Tier (0 to 5). The Bus Number starts at 4114 and can be changed.
  3. Tick Spare and enter the spare bus number if you are on a spare bus.
  4. Tick Route Sub/Breakdown if you are covering another route or a bus breakdown. It clears after you save.
  5. Tap Start Route Now or type the Start Time. Fill in the End Time when you finish (the Now button stamps the current time).
  6. Add the kids count, weather, notes and anything else that applies, then tap Save Log.

The Week tab lists your saved logs and totals. To fix a log, open it and use its edit option; it loads back into the form so you can save it again.

Log kid counts only. Do not put student names in notes if your district does not allow it.

3. Fill the form from a note

Instead of typing, you can say or paste one line and let the app fill the form.

Example line:

route 336 tier 0 bus 4114 PM 15 kids
  1. Open the Voice tab.
  2. Tap Start Mic and speak the line, or paste it into the box.
  3. Tap Fill Form From Text (or copy the line anywhere and tap Paste & Fill From Clipboard).
  4. A message lists what was filled. Go to the Today tab, check it, and tap Save Log.

It understands route, tier, bus, kids, AM/PM, delay minutes ("10 minutes late"), weather, spare bus, your school's name, and the words "breakdown" or "route sub". Numbers in words work too ("twenty five students"). Nothing is saved until you tap Save Log.

Using a link

Opening the app with your note after ?gardian= fills the form the same way, for example:

https://bus-gardian.netlify.app?gardian=route%20336%20tier%200%20bus%204114%20PM%2015%20kids

In Settings, each device section has a Generate Link button that builds a link like this from its template.

4. Send your logs to Google Sheets

Each time you save a log, the app can also send it to a Google Sheet. You set this up once.

A. Make the sheet and the script

  1. Go to sheets.google.com and create a new blank spreadsheet. Name it "Bus LogBook".
  2. Click Extensions → Apps Script.
  3. Delete everything in the editor, then paste the script below.
  4. Click the save icon.
const HEADERS = ["id","localDate","localTime","school","route","tier","bus",
  "spare","spareBus","breakdownCover","startTime","endTime","weather","road",
  "tripShift","traffic","delayMin","odometer","kids","notes","issues","createdAt"];

function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Logs") || ss.insertSheet("Logs");
  if (sheet.getLastRow() === 0) sheet.appendRow(HEADERS);

  var data = {};
  try { data = JSON.parse(e.postData.contents); }
  catch (err) { data = { notes: "Unreadable data" }; }

  if (data.test) {
    data = { school: "TEST", notes: "Webhook test" };
  }

  sheet.appendRow(HEADERS.map(function (h) {
    return data[h] === undefined ? "" : data[h];
  }));
  return ContentService.createTextOutput("ok");
}

B. Publish it as a web app

  1. Click Deploy → New deployment.
  2. Click the gear icon and choose Web app.
  3. Set Execute as to Me.
  4. Set Who has access to Anyone. (The app cannot sign in to Google, so this is required.)
  5. Click Deploy, then Authorize access and approve with your Google account. If Google says the app is unverified, click Advanced and continue. It is your own script.
  6. Copy the Web app URL. It ends in /exec.
Keep that URL private. Anyone who has it can add rows to your sheet.

C. Connect the app

  1. Open the app, go to Settings, and find Google Sheets Webhook Connection.
  2. Paste the URL into Webhook URL.
  3. Turn Auto Save on. Logs are only sent when Auto Save is on.
  4. Tap Save All, then Test Webhook.
  5. Open your sheet. A new Logs tab should appear with a TEST row. You can delete that row.
The app sends data in a way that cannot report errors back, so it will say "sent" even if the sheet did not receive it. Always check the sheet after the test. If you later edit the script, use Deploy → Manage deployments → edit → New version, or the changes will not take effect.

What each column means

ColumnMeaning
localDate, localTimeWhen the log was saved
school, route, tier, busThe main run details
spare, spareBusWhether a spare was used, and its number
breakdownCoverThe Route Sub/Breakdown box
startTime, endTime, delayMinTimes and minutes late
weather, road, tripShift, trafficConditions, and AM/PM shift

Only logs saved after you turn Auto Save on are sent. To move older logs into the sheet, use the Export tab to download a CSV and import it with File → Import.

5. AI devices (optional)

You do not need any of these devices to use the app. Devices that can record what is said word for word are there to help you remember exactly what was said in a conversation, so details do not get twisted by memory. They are a helpful extra, not a requirement.

Before you record anyone, check your district's policy and your local recording rules.

All of these work the same way in the end: the device captures what you say, you get that text, and the app fills the form from it. The app itself only reads text. It does not connect to any device directly, so you always check the form and tap Save Log yourself.

What to say, for every device: a short line such as route 336 tier 0 bus 4114 PM 15 kids. Say it clearly and include the words route, tier, bus and kids.

Looki L1 via Claude Code

Looki connects through its own sign-in, which a web page cannot do, so the link goes through Claude Code.

  1. On your computer, install the plugin: npx -y plugins add looki-ai/looki-plugin --target claude-code -y
  2. Restart Claude Code, or run /reload-plugins.
  3. Run /mcp, choose looki, then Authenticate, and sign in on the Looki page that opens. Type your login only on Looki's own page.
  4. Run /mcp again and make sure looki shows as connected.
  5. Wear your Looki and say your log line aloud.
  6. In Claude Code, ask: "Find my latest Looki moment and give me the bus log as one line: route, tier, bus, AM or PM, kids."
  7. Copy that line. In the app, open Voice and tap Paste & Fill From Clipboard.

This depends on Looki capturing and summarizing what you said. Check the line Claude gives you against what you said before you save.

Ray-Ban Meta glasses

  1. In the app, open Settings, find Ray-Ban Meta Glasses, and turn Meta Enabled on.
  2. Say: "Hey Meta, take a note: Gardian, route 336 tier 0 bus 4114 PM 15 kids."
  3. Open the note in the Meta app and copy its text.
  4. In the app, open Voice and tap Paste & Fill From Clipboard.

Cyan (HeyCyan) smart glasses

  1. In Settings, find the Cyan section and turn Cyan Enabled on.
  2. Wear the glasses and power them on.
  3. Say: "HeyCyan, take a note: Gardian, route 336 tier 0 bus 4114 PM 15 kids."
  4. Open the Cyan app, copy the note's transcript, then use Paste & Fill From Clipboard on the Voice tab.

Fieldy pendant or watch

  1. In Settings, find Fieldy and turn Fieldy Enabled on.
  2. Wear Fieldy, make sure it is paired to your phone by Bluetooth, and tap it to start listening.
  3. Say: "Gardian, route 336 tier 0 bus 4114 PM 15 kids."
  4. Open the Fieldy app, copy the transcript line, then use Paste & Fill From Clipboard on the Voice tab.
About "Auto Sync" buttons in Settings. The Fieldy section says the app can receive transcripts automatically through the webhook. It cannot: the webhook only sends logs out to Google Sheets. For now, use the copy-and-paste steps above.

No device? Use your phone's own voice typing

On the Voice tab, tap Start Mic and say the line, or tap the microphone on your phone's keyboard in the text box.

6. Backup and reset

  • Export: open the Export tab and download your logs as a CSV file. Open it in Excel or Google Sheets.
  • Reset: Settings → Clear and Reset - All Keys removes logs, schools and settings from this phone. You must tick the confirmation box, then tap Yes, Delete All. It cannot be undone, so export first.

7. Troubleshooting

  • The app looks old after an update. Refresh the page, or close and reopen the home-screen app.
  • Paste & Fill says it can't read the clipboard. Your browser blocked it. Paste into the Voice text box and tap Fill Form From Text.
  • "I couldn't find log details." Include words like route, tier, bus and kids, for example route 336 tier 0 bus 4114 PM 15 kids.
  • Nothing reaches Google Sheets. Check that Auto Save is on, the URL ends in /exec, access is set to Anyone, and the script was deployed as a web app. Then run Test Webhook again.
  • Logs missing. Logs live in one browser on one phone. Open the app in the same browser you used before.
